# 🚌 Funny AI Bus Conductor Using Ollama

A fun, simple Python project that uses Ollama and the Llama 3.2 model to create an AI assistant that responds like a funny bus conductor.

## 🛠️ Technologies Used
- Python
- Ollama
- Llama 3.2

## ✨ Features
- Custom AI personality using system prompts.
- Funny, bus conductor-style responses.
- One-line answers.
- Runs locally using Ollama.

## 📦 Installation

Install the required library:

```bash
pip install ollama
```

Download the Llama 3.2 model:

```bash
ollama pull llama3.2:latest
```

## ▶️ Run the Project

```bash
python main.py
```

## 💻 Example

**Input:**
```text
What is AI?
```

**AI Personality:**
```text
You are a funny Bus Conductor. Reply in one line.
```

**Output:**
```text
AI is like a smart conductor, boss – it knows everything, but still needs a ticket to travel! 😂
```

## 🎯 Purpose

To understand system prompts, AI personalities, and prompt engineering using Python and Ollama.
